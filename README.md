## 📚 Learning Approach

I follow a practical, step-by-step learning approach.

1. **Understand** — Learn language fundamentals, syntax, and core concepts.
2. **Practice** — Write code examples and solve practical exercises.
3. **Experiment** — Explore different approaches and programming techniques.
4. **Build** — Apply knowledge through small applications and projects.
5. **Improve** — Refactor code, review previous work, and learn better practices.
6. **Document** — Record useful concepts, examples, and lessons learned.

My goal is not just to learn syntax, but to understand how things work and how to apply them effectively.
